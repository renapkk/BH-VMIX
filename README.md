# BH VMIX — SSL 12 の入力1〜4をミックスして通話アプリに送る（macOS）

Discord や Zoom などの通話アプリは、入力デバイスの先頭 ch しか使えません。
BH VMIX は SSL 12 の入力1〜4をまとめてステレオまたはモノラルの2ch にし、**BlackHole 2ch** に流します。
通話アプリのマイクに「BlackHole 2ch」を選べば、ミックスした音が相手に届きます。

```
SSL 12 In 1〜4 → 各ch: Limiter → Pan → Fader → Mute ┐
                                                     ├→ Master（Fader → Limiter）→ BlackHole 2ch → 通話アプリのマイク
            （In 1-2 は Link でステレオペアにできる）  ┘
```

### 機器セット「SSL12+BH」とは

BH VMIX が裏で使う「配線」です。通話アプリでは選びません。

- SSL 12 と BlackHole は、それぞれ別のクロックで動いています。2台を別々に開くと、わずかなクロックのズレ（ドリフト）がたまって、ノイズや音切れの原因になります。
- 機器セットにすると、Core Audio が2台を「1台の機材」としてまとめます。**クロックソースを SSL 12**（ワードクロックのマスター）にし、**BlackHole 側はドリフト補正 ON**（SSL 12 に合わせて自動でサンプルレート変換）にします。
- BH VMIX はこの1台を開き、入力（SSL 12 の In 1〜4）と出力（BlackHole）を同じタイミングで扱います。

## 0. かんたんな使い方（アプリ版 BH VMIX.app）

ターミナルを使わずに、設定ウィンドウから操作できるアプリ版があります。**ふだんはこちらを使ってください。**
ほかのアプリと同じく **Dock と ⌘Tab に表示** され、メニューバーにも「VMIX ●」が出ます。
### ダウンロード

**[BH-VMIX.zip をダウンロード](https://github.com/renapkk/BH-VMIX/releases/latest/download/BH-VMIX.zip)**（最新版。過去の版は [Releases](https://github.com/renapkk/BH-VMIX/releases) にあります）

`BH-VMIX.zip` には、アプリと「はじめにお読みください.txt」が入っています。
必要なもの：Apple シリコン（M1 以降）の Mac、macOS 13 以降、SSL 12、BlackHole 2ch（別途インストール）。

### はじめて使うとき（どの Mac でも同じ）

1. **BlackHole 2ch をインストール**
   - BH VMIX には BlackHole は入っていません。[公式ページ](https://existential.audio/blackhole/) から入手してインストールします（Homebrew がある Mac なら `brew install --cask blackhole-2ch` でも可）
   - インストールが終わったら **Mac を再起動**
2. **BH VMIX.app を「アプリケーション」フォルダに入れる**
   - `BH-VMIX.zip` をダブルクリックして展開し、出てきた `BH VMIX.app` をアプリケーションフォルダへドラッグ
3. **初回だけの起動手順**（Apple の審査を受けていないアプリなので、初回は警告が出ます）
   - `BH VMIX.app` をダブルクリック →「開けません」などの警告が出たら「完了」で閉じる
   - **システム設定 > プライバシーとセキュリティ** を開き、下の方の「“BH VMIX”は…」の横にある **「このまま開く」** を押す
   - 2回目以降はふつうにダブルクリックで起動できます
   - 「このまま開く」が出ない場合は、ターミナルで次を実行してから開き直してください（ダウンロードしたファイルに付く「インターネットから来た」という印を外すコマンドです）
     ```bash
     xattr -dr com.apple.quarantine "/Applications/BH VMIX.app"
     ```
4. **マイク権限を許可**：「“BH VMIX”がマイクへのアクセスを求めています」と出たら **許可**
5. **機器セットを作る**：設定ウィンドウ下の **「機器セットを作成」** を押す（メニューバーからも可）
   - Audio MIDI 設定での手作業は不要です（手で作る場合は2章を参照）
6. **通話アプリの設定**（Discord・Zoom など共通。5章のおすすめ設定も参照）

| 通話アプリの設定 | 選ぶデバイス |
|---|---|
| マイク（入力） | **BlackHole 2ch** |
| スピーカー（出力） | **SSL 12**（ヘッドホンで聞く） |

- **SSL12+BH はマイクに選ばない**：通話アプリは先頭の ch しか使わないので、SSL 12 の In 1 だけが届きます。
- **BlackHole 2ch はスピーカーに選ばない**：相手の声がミックスに混ざって相手に返ります（ループ）。

### 設定ウィンドウ

アプリを起動すると開きます。閉じたあとは、次のどれかで開き直せます。

- **Dock の BH VMIX のアイコンをクリック**（または、アプリをもう一度ダブルクリック）
- 画面上部のメニュー「BH VMIX」→「設定ウィンドウを開く」（**⌘,**）
- メニューバーの「VMIX ●」→「設定ウィンドウを開く」

ウィンドウを閉じても音は止まりません。止めるときは **⌘Q**（または Dock のアイコンを右クリック →「終了」）でアプリを終了します。
変えた値は **自動で設定ファイルに保存** され、次に起動したときも同じ状態で始まります。

| 場所 | 項目 | 内容 |
|---|---|---|
| 上の帯 | 状態 | ● 動作中 ／ 接続待ち ／ 停止 ／ Test Tone ／ SSL 12 なし |
| 上の帯 | Output | Stereo（Pan で左右に振る）／ Mono（全部を合わせて L/R 両方に同じ音） |
| 上の帯 | Buffer Size | バッファサイズ。小さいほど遅延が少なく、大きいほど安定（変えると一瞬音が切れて開き直す） |
| 各チャンネル | 名前 | クリックすると書き換えられる |
| 各チャンネル | Limiter | ON/OFF、スレッショルド（Thr、-30〜0 dB）、減衰量のメーター。Fader の前にかかる |
| 各チャンネル | Pan | 左右の定位（C ／ L 50 ／ R 50 のように表示） |
| 各チャンネル | Fader | -60〜+12 dB（0.5 dB 刻み）。左にメーター |
| 各チャンネル | Mute | ON で深い赤になる |
| Master | Limiter ／ Fader | セーフティリミッター（-1 dBFS）と、全体の音量。L/R メーター |
| Preset の帯 | 一覧 ／ Load ／ Save… | ミックス設定の保存と読み出し（下を参照） |
| 案内の帯 | 通話アプリの設定 | 通話アプリで選ぶデバイス（IN = BlackHole 2ch、OUT = SSL 12） |
| 下の帯 | 機器セットを作成 | 機器セット「SSL12+BH」を自動で作る |
| 下の帯 | Link In 1-2 | In 1 と In 2 をステレオリンクする（下を参照） |
| 下の帯 | Test Tone  -12 dBFS | 入力の代わりに 1kHz のサイン波（ピーク -12 dBFS、RMS 約 -15 dBFS）を左右両方に流す。**通話中は使わないこと** |
| 下の帯 | L/R Test | 1kHz を **左だけ（0.9秒）→ 右だけ（0.9秒）** と交互に流す。相手にステレオで届いているかの確認用 |

#### Preset（プリセットの保存と読み出し）

設定ウィンドウでの変更は自動保存されるので、そのままでは前の状態に戻せません。戻りたい状態は **プリセット** として残しておきます。

- **Save…**：今のミックス設定を保存します。名前の先頭には **保存した日付と時刻（例: `261027_2259_`）が自動で入り**、そのあとに好きな名前を付けられます（空欄でも可。同じ名前があれば末尾に `_2` などが付きます）。
- **Load**：一覧で選んだプリセットを読み込みます（確認のダイアログが出ます）。今の設定は上書きされるので、残したい場合は先に Save… してください。
- 読み込むのは Fader・Pan・Mute・Limiter・Link・Bal・Output・Master と、チャンネル名です。デバイスや Buffer Size は読み込みません（音が止まらないように）。
- 一覧は新しい順に並びます。保存先は `~/Library/Application Support/BH VMIX/presets/` で、メニューバーの「プリセットのフォルダを開く」から開けます。いらないプリセットは、そこでファイルを削除してください。

#### Link In 1-2（ステレオリンク）

- **はじめから ON** です。In 1 が L、In 2 が R に固定され、2列分の幅の「In 1-2 · Linked」チャンネルにまとまります。
- Pan の代わりに **Bal（バランス）** で左右の量を調整します。
- Fader・Mute・Limiter は1つの操作で L/R 両方が動きます。リンクした瞬間に In 1 の設定が In 2 にコピーされます。
- Limiter は L/R の大きい方に合わせて **両方を同じ量だけ** 下げるので、定位がずれません。
- Output が Mono のときは、L+R を -3 dB して両方に出します。

### メニューバー

【一般論】macOS では、アプリの側からメニューバーのアイコンを優先して表示させることはできません。アイコンが多いとノッチの裏に隠れることがあるので、そのときは Dock か ⌘Tab から開いてください（⌘ キーを押しながらメニューバーのアイコンをドラッグすると、並び順を変えられます）。

| 表示 | 意味 |
|---|---|
| `VMIX ●` | 動作中（SSL 12 の入力1〜4を BlackHole に送っている） |
| `VMIX …` | 接続待ち（SSL 12 や機器セットが見つからない。見つかれば自動で再開） |
| `VMIX ○` | 停止中 |

メニューには、設定ウィンドウを開く、開始/停止、Mute、Output、Test Tone、機器セットの作成、BlackHole のダウンロードページ、設定ファイルを開く、プリセットのフォルダを開く、設定を再読み込み、ログを開く、ログイン時に起動、終了 があります。

- アプリ版の設定ファイルは `~/Library/Application Support/BH VMIX/config.toml` です（初回起動時に自動で作られます）。設定ウィンドウで値を変えると上書き保存されるので、手で書いたコメントは残りません。
- 「ログイン時に起動」は、アプリの **今ある場所** を登録します。アプリケーションフォルダに移してから ON にしてください（移した場合は一度 OFF → ON にし直す）。ログイン時は設定ウィンドウを開かずに起動します（Dock のアイコンをクリックすれば開きます）。

### 相手にステレオで届いているか確かめる

**L/R Test** を押して、相手に「左・右・左・右」と交互に聞こえればステレオで届いています。両方から同じように聞こえたらモノラルです。

【一般論】Zoom はスマホ・タブレットのアプリだとモノラルで再生されるので、送る側がステレオでも、相手にはモノラルで聞こえます。確かめるときは、相手にパソコンの Zoom とステレオのヘッドホンで聞いてもらってください。

### アプリを作り直す（開発する人向け）

```bash
./scripts/build_app.sh
```

`dist/BH VMIX.app` と、ほかの Mac に渡すための `dist/BH-VMIX.zip` ができます。

`vendor/BlackHole/` に BlackHole の公式インストーラー（`BlackHole2ch-0.7.1.pkg`）とライセンス文（`BlackHole_LICENSE.txt`）を置いておくと、**身内に渡す用の `dist/BH-VMIX-with-BlackHole.zip`** も作られます。BlackHole をダブルクリックで入れられる版です。

## 1. 準備

### 1-1. BlackHole 2ch のインストール

```bash
brew install --cask blackhole-2ch
```

途中で Mac のログインパスワードを聞かれます。インストール後は **Mac を再起動** すると確実です。

### 1-2. Python の環境（venv）

venv は「このプロジェクト専用のパッケージ置き場」です。システムの Python を汚さずに済みます。

```bash
git clone https://github.com/renapkk/BH-VMIX.git
cd BH-VMIX
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 1-3. 設定ファイル

```bash
cp config.example.toml config.toml
```

`config.toml` を編集すると、ゲイン・パン・ミュートなどを調整できます（詳しくは「4. 設定ファイル」）。

## 2. 機器セット「SSL12+BH」の作り方

1. **Audio MIDI 設定**（アプリケーション > ユーティリティ）を開く
2. 左下の **＋** →「**機器セットを作成**」
3. 作られた「機器セット」をダブルクリックし、名前を **`SSL12+BH`** に変える（`config.toml` の `device` と完全に同じにする）
4. 右側の一覧で **SSL 12** と **BlackHole 2ch** の「使用」にチェックを入れる
   - チェックした順に並びます。**SSL 12 → BlackHole 2ch の順** がおすすめです（順番が逆でも ch は自動判定されます）
5. **クロックソース** を **SSL 12** にする
6. **BlackHole 2ch** の行の **ドリフト補正** にチェックを入れる（SSL 12 側はチェック不要）
7. フォーマット（サンプルレート）を **48,000 Hz** にする

設定できたら次のコマンドで確認します。

```bash
.venv/bin/python -m ssl_mixer --list
```

「機器セットの中身」に SSL 12 が `★クロックソース`、BlackHole 2ch が `[ドリフト補正ON]` と表示されれば OK です。
設定が推奨と違う場合は ⚠ で知らせます。

> 機器セットの名前は自由ですが、`config.toml` の `device` と一致させてください。
> 「機器セットa」のような既存の機器セットとは別に新しく作るのがおすすめです。

---

## 3. 使い方

| コマンド | 内容 |
|---|---|
| `.venv/bin/python -m ssl_mixer --list` | 全デバイスと in/out の ch 数、機器セットの中身、判定された ch を表示 |
| `.venv/bin/python -m ssl_mixer --test-tone` | 入力の代わりに 1kHz サイン波（-12dBFS）を BlackHole に出す。動作確認用 |
| `.venv/bin/python -m ssl_mixer` | ミックスを開始（Ctrl+C で終了） |
| `.venv/bin/python -m ssl_mixer --meter` | ミックスしながらピークメーターを表示 |
| `.venv/bin/python -m ssl_mixer --config 別の設定.toml` | 設定ファイルを指定 |

### おすすめの確認手順

1. `--list` で機器セットと ch 判定を確認
2. `--test-tone` を動かしたまま、Discord の **設定 > 音声・ビデオ > 入力デバイス** を BlackHole 2ch にし、「マイクテスト」で 1kHz が聞こえることを確認
3. Ctrl+C で止めて、`--meter` 付きで通常起動し、SSL 12 に入れた音でメーターが振れることを確認

### SSL 12 の抜き差し

動作中に SSL 12 を抜いたり、機器セットが消えたりしても止まりません。
`reconnect_interval`（既定3秒）おきに再接続を試み、戻ってきたら自動で再開します。

## 4. 設定ファイル（config.toml）

ch 番号はすべて Audio MIDI 設定と同じ **1始まり** です。

| 項目 | 既定値 | 内容 |
|---|---|---|
| `device` | `"SSL12+BH"` | 開く機器セットの名前 |
| `source_device` / `sink_device` | `"SSL 12"` / `"BlackHole 2ch"` | 機器セット内の入力元／出力先（ch 自動判定に使う） |
| `samplerate` | `48000` | 希望のレート。機器セットが別のレートならそちらに合わせる |
| `blocksize` | `256` | バッファサイズ（1回に処理するサンプル数。Pro Tools の H/W バッファサイズと同じ）。音が途切れるなら `512` に |
| `output_mode` | `"stereo"` | `"mono"` にするとパンを無視して両 ch に同じ信号を出す |
| `master_gain_db` | `0.0` | マスターゲイン |
| `limiter` | `true` | マスター段のセーフティリミッター（-1dBFS） |
| `reconnect_interval` | `3.0` | 再接続を試みる間隔（秒） |
| `input_channels` | （自動） | 例: `[1, 2, 3, 4]`。手動で入力 ch を指定する場合 |
| `output_channels` | （自動） | 例: `[17, 18]`。手動で出力 ch を指定する場合 |
| `link_in_1_2` | `true` | In 1 と In 2 をステレオリンクする（設定ウィンドウの Link In 1-2） |
| `link_balance` | `0.0` | リンク中のバランス。-1（左）〜 +1（右） |

入力ごとの設定は `[[inputs]]` を並べて書きます（上から順に入力1, 2, 3, …）。

```toml
[[inputs]]
name = "Vo"
gain_db = 0.0
pan = 0.0      # -1（左）〜 +1（右）。センターで左右とも -3dB（コンスタントパワー）
mute = false
limiter = false               # チャンネルの Limiter（Fader の前にかかる）
limiter_threshold_db = -6.0   # Limiter のスレッショルド（-60〜0 dB）
```

- ch を自動判定する場合、`[[inputs]]` の数だけ SSL 12 の入力1から順に使います（4つ書けば入力1〜4）
- **Discord はモノラルで送ることが多い** ので、パンで左右に振っていると片側だけ小さく聞こえることがあります。迷ったら `output_mode = "mono"` がおすすめです

## 5. 通話アプリ（Discord・Zoom など）側の設定

どの通話アプリでも、**マイク（入力）は BlackHole 2ch、スピーカー（出力）は SSL 12** です。
機器セット「SSL12+BH」は BH VMIX 専用なので、通話アプリでは選びません。

### Discord（設定 > 音声・ビデオ）

| 項目 | 推奨 |
|---|---|
| 入力デバイス | **BlackHole 2ch** |
| 出力デバイス | SSL 12 など（**BlackHole 2ch にはしない**。相手の声がミックスに戻ってループします） |
| 入力感度の自動調整 | OFF にして、感度スライダーを一番左（常に送信）に |
| ノイズ抑制（Krisp など） | **なし／OFF** |
| エコー除去 | **OFF** |
| 自動ゲイン調整 | **OFF** |

ノイズ抑制・エコー除去・自動ゲインは、音楽や作り込んだミックスを壊してしまうので OFF がおすすめです。
ヘッドホンでモニターしていればエコー除去は不要です。

### Zoom（設定 > オーディオ）

| 項目 | 推奨 |
|---|---|
| マイク | **BlackHole 2ch** |
| スピーカー | SSL 12 など（**BlackHole 2ch にはしない**） |
| マイク音量を自動で調整 | OFF |
| 詳細 > オリジナルサウンド（ミュージシャン向け） | **ON**（会議中に画面左上の「オリジナルサウンド」も ON にする） |

【一般論】オリジナルサウンドを ON にすると、Zoom のノイズ抑制やエコー除去が切れて、ミックスがそのまま届きます。

## 6. マイク権限

macOS では、録音するアプリに **マイク権限** が必要です。
権限が無いと、エラーにはならずに **無音** になります。

- 初回実行時に「“ターミナル”がマイクへのアクセスを求めています」と出たら **許可**
- 後から変えるには: **システム設定 > プライバシーとセキュリティ > マイク** で、実行しているアプリ（ターミナル、iTerm など）を ON にして、そのアプリを再起動

このツールは、入力が3秒以上 **完全な 0（デジタルゼロ）** のままだと、権限が無い可能性を表示します。

## 7. トラブルシュート

### 「SSL 12 が認識されません」と出る
SSL 12 が Mac から見えていません。USB ケーブルと SSL 12 の電源を確認してください。
つながると自動で再開します（このお知らせは、見つからなくなったときに1回だけ出ます）。
設定ウィンドウの状態表示も「● SSL 12 なし」になります。

### 起動直後に「オーディオの準備が終わりません」と出る
マイクへのアクセスを求める画面が出ていないか確認し、出ていたら「許可」を押してください。
アプリを作り直した（ビルドし直した）ときにも、もう一度聞かれることがあります。

### Discord で音が聞こえない
1. `--test-tone` で 1kHz が届くか確認 → 届かないなら Discord の入力デバイス設定か機器セットの問題
2. テストトーンは届くのに通常時は無音 → マイク権限（6章）か SSL 12 の入力レベルを確認。`--meter` で入力メーターが振れるか見る
3. 「入力が完全な無音です」と出る → マイク権限を確認

### ブツブツ・プチプチ音がする
- バッファサイズ（`blocksize`）を `512` に上げる
- 機器セットのクロックソースが SSL 12、BlackHole のドリフト補正が ON になっているか（`--list` で確認できます）
- `--meter` の `xrun`（処理が間に合わなかった回数）が増えていないか
- 【一般論】Python は処理の合間にメモリの自動回収などが入るため、専用アプリより音切れに弱い面があります。重い作業と同時に使うときはバッファサイズ（`blocksize`）を大きめにしてください

### 「機器セット「SSL12+BH」が見つかりません」
- Audio MIDI 設定の機器セット名と `config.toml` の `device` が完全一致しているか（全角・半角、スペースにも注意）
- `--list` の一覧に表示されているか

### ch がずれている／違う入力が鳴る
- `--list` の「機器セットの中身」で、各デバイスが何 ch 目に割り当てられているか確認
- 自動判定がうまくいかないときは `input_channels` / `output_channels` を手動で書く
  - 例: SSL 12（入力16/出力8）→ BlackHole（入力2/出力2）の順なら、BlackHole の出力は 9, 10

### 起動しても「開始」と出ずに固まる／「ストリームを開く処理が応答しません」
Core Audio の音声サーバー（coreaudiod）が固まっている可能性があります。
`afplay` など他のアプリでも音が出ないか確認し、Mac を再起動するか、次のコマンドを実行してください（パスワードを聞かれます）。

```bash
sudo killall coreaudiod
```

### サンプルレートの表示が 48000 以外になる
機器セット（または SSL 12）が別のレートで動いています。Audio MIDI 設定で 48,000 Hz に揃えてください。

  paths.py      アプリ版の設定・ログの置き場所

  presets.py    プリセットの保存と読み出し
